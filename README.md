# Snapchat SS06 Appeal Helper

Petit outil Python qui aide à préparer une demande de réexamen lorsqu'un appareil affiche le code **SS06** sur Snapchat.

## Important

Ce projet **ne débloque pas un appareil**, ne contourne pas les protections de Snapchat et ne modifie pas l'application. Il sert uniquement à préparer une demande d'assistance.

## Installation

Aucune dépendance externe n'est nécessaire.

```bash
git clone https://github.com/TON-PSEUDO/snapchat-ss06-appeal.git
cd snapchat-ss06-appeal
python3 main.py
```

Sous Windows :

```bash
python main.py
```

## Utilisation

Le programme demande :
- ton nom d'utilisateur Snapchat ;
- ton adresse e-mail (facultative).

Il génère ensuite un message que tu peux copier dans ta demande d'assistance.
